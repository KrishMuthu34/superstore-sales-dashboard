# Sales Dashboard (Tableau)

Interactive sales dashboard built with Tableau Public using a sample (synthetic) dataset of 1000 orders.

## Live Dashboard
[Tableau Public link]

## Dataset
- sales_data_1000.csv, 1000 records, Jan 2024 to Dec 2025
- Columns: Order_ID, Order_Date, Region, State, Category, Product, Sales, Profit, Discount, etc.

## Tools
Tableau Public, CSV

## Analysis Done
- Monthly sales trend
- Region and state-wise sales
- Category-wise sales and profit
- Top 10 products
- State-wise Map
